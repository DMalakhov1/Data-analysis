## 1. T-Bank kicksharing case

**Папка:** [`tbank_case`](./tbank_case)

### Задача

Провести разведочный анализ данных по поездкам на самокатах, выявить основные паттерны поведения пользователей и сформулировать продуктовые гипотезы для роста сервиса.

В проекте подготовлены:

- Jupyter Notebook с EDA;
- PDF-презентация с основными выводами;
- PPTX-презентация;
- исходный датасет в архиве.

### Данные

Используется датасет по поездкам на самокатах:

```text
tbank_case/kicksharing.csv.zip
```

Размер данных:

- **396 749 строк**;
- **20 колонок**.

Основные группы признаков:

- пользователь: `party_rk`, `gender_cd`, `age`, `education_level_cd`, `marital_status_cd`;
- география: `lvn_state_nm`, `book_time_zone_cd`;
- поездка: `distance_km`, `created_dttm`, `book_start_dttm`, `book_end_dttm`;
- экономика: `minute_cost`, `activation_cost`, `hold_amount`, `nominal_price_rub_amt`;
- лояльность: `loyalty_accrual_rub_amt`, `loyalty_accrual_bns_amt`.

### Что сделано

В ноутбуке реализованы:

- первичный EDA;
- переименование колонок для удобства анализа;
- проверка пропусков и дублей;
- анализ категориальных признаков;
- анализ числовых признаков;
- анализ выбросов через IQR и перцентили;
- анализ временных рядов;
- анализ поведения пользователей;
- анализ географии поездок;
- анализ экономики поездок;
- проверка мультиколлинеарности;
- визуализация распределений и зависимостей;
- формулирование продуктовых гипотез.

### Основные выводы

По результатам EDA были выделены следующие паттерны:

- основная аудитория — молодые пользователи примерно 20–30 лет;
- мужчины совершают большую часть поездок — около 70–80%;
- основные регионы по количеству поездок: Москва, Московская область, Санкт-Петербург, Свердловская область, Краснодарский край;
- поездки чаще короткие: средняя длительность около 7–13 минут, расстояние чаще 1–3 км;
- пиковые часы поездок приходятся на утро и вечер;
- средняя стоимость минуты — около 7,6 руб.;
- старт аренды фиксирован: 30 или 50 руб.;
- средний чек поездки — около 120,2 руб.;
- средний кэшбэк — около 31,5 руб.;
- доля поездок с кэшбэком — около 93,35%.

### Продуктовые гипотезы

На основе анализа сформулированы гипотезы:

1. **Прогрессивная скидка после 10 минут поездки**  
   Может увеличить среднюю длительность поездки и стимулировать более длинные сценарии использования.

2. **Персонализированные push-уведомления для пользователей старше 30 лет**  
   Может повысить активность возрастной группы, которая сейчас пользуется сервисом реже.

3. **Геймификация и бонусы за серию поездок**  
   Может повысить retention и частоту повторных поездок.

## Как запустить

Склонируйте репозиторий:

```bash
git clone https://github.com/DMalakhov1/Data-analysis.git
cd Data-analysis
```

Создайте виртуальное окружение и установите основные зависимости:

```bash
pip install pandas numpy matplotlib seaborn plotly geopandas scipy jupyter
```

Откройте нужный ноутбук:

```bash
jupyter notebook
```

Далее перейдите в папку интересующего проекта и запустите соответствующий `.ipynb`.
