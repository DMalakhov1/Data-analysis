# Data Analysis — проекты по анализу данных и продуктовой аналитике

Репозиторий с учебными и прикладными проектами по анализу данных. Внутри собраны EDA-кейсы, работа с табличными данными, визуализация, анализ временных рядов, геоаналитика и продуктовые выводы на основе данных.

Фокус репозитория — показать полный аналитический цикл: загрузка и очистка данных, проверка пропусков и дублей, исследовательский анализ, визуализация, формулирование выводов и перевод результатов анализа в продуктовые гипотезы.
